# Design & accessibility review — 2026-11-18

Production build (`next build` + `next start`), Chromium via Playwright.
Widths 1280 / 375 / 320, light and dark, 200% zoom (640 px), reduced motion.

## Accessibility (WCAG 2.1 AA)

**axe-core** (wcag2a/aa, wcag21a/aa, best-practice): 0 violations, 0 incomplete in all four runs
(light/dark × 1280/375).

| # | Finding | WCAG | Severity | Status |
| --- | --- | --- | --- | --- |
| 1 | Phone menu: focus stayed on the toggle when the menu opened (a `visibility` transition kept the links hidden on the first frame) | 2.4.3 Focus order | 🟡 Major | Fixed: visibility flips at once on open, transitions only on close; focus moves to "Work" |
| 2 | Escape closed the menu but focus was not returned explicitly | 2.4.3 | 🟢 Minor | Fixed: focus returns to the toggle |
| 3 | Small targets on phone: name link 26 px tall, "Visit locallyeg.com" 24 px, e-mail link 35 px | 2.5.5 (AAA) / 2.5.8 | 🟢 Minor | Fixed: all ≥ 44 px |
| 4 | Links opening a new tab gave no warning to screen readers | 3.2.5 (AAA) | 🟢 Minor | Fixed: visually hidden "(opens in a new tab)" |

Checked and passing:

- Tab order follows the page (skip link → nav → theme → resume → hero CTAs → case-study link → contact); all 19 stops show a 2 px accent outline.
- Closed phone menu has 0 focusable links (`invisible`).
- 200% zoom: reflows, no horizontal scroll. No horizontal scroll at 320 / 375 / 1280.
- One `h1`; `h2` per section, `h3` per case study / role. `lang="en"`. Landmarks: header, nav, main, footer.
- Decorative art has `alt=""`; portrait has alt text; tech logos are `aria-hidden` next to their names.
- Reduced motion: animations and smooth scroll off.

## Design critique

**Overall:** the build matches the approved mockup. The hierarchy is clear: serif headline, then muted lead, then CTAs, then facts.
Case studies carry the page through the numbers from the résumé, not adjectives.

| Finding | Severity | Status |
| --- | --- | --- |
| Dark mode: contact band (#161A19) barely separates from the page (#0E1110) | 🟢 Minor | Fixed: hairline top border |
| Phone menu had no line under the header, so it merged into it | 🟢 Minor | Fixed: `border-y` |
| 320 px: the three metrics are tight and their labels wrap to 3 lines | 🟢 Minor | Gap reduced; acceptable. Option: 1-column metrics under 360 px |
| Phone and LinkedIn appear twice (About and Contact) | — | Kept on purpose (requested) |
| Desktop hero: art sits vertically centred against a tall text column, leaving space under it | 🟢 Minor | Left as is; matches mockup |

**What works:** one accent used sparingly; consistent 24 / 40 px gutters; monochrome logos keep the palette;
dark mode reads as designed rather than inverted; illustrations stay consistent across all six.
